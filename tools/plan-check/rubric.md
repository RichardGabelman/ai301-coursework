## Checks

| Check | Evidence | Pass condition | Weight |
|---|---|---|---|
| correct diagnosis | the plan comment, the issue thread, the original issue post | Pass if the diagnosis given in the plan comment matches the established cause of the issue | required |
| established scope | the plan comment | pass if the plan says what it will change, at least each file it will change | required |
| test plan | the plan comment, the original issue post, repro evidence | Pass if the plan either adds an automated test addressing the issue, or details steps taken to manually test the new changes to ensure they actually address the original issue | required |
| conventions | the plan comment, the original issue post, the thread, repo's AI policy | Pass if the comment follows any explicit maintainer direction present in the thread. Every single plan you read will have used AI in some way, pass if either there is no repo AI disclosure policy, or if the plan discloses AI usage per the repo's AI policy | required |

## Verdict rule

Accept only when all required checks pass.
